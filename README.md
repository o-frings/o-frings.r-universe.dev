# o-frings.r-universe.dev

Config repository for the [o-frings R-universe](https://o-frings.r-universe.dev).

`packages.json` lists packages built and indexed by R-universe for this account.

Collaborators install any listed package with:

```r
install.packages("<pkg>",
                 repos = c("https://o-frings.r-universe.dev",
                           "https://cloud.r-project.org"))
```
